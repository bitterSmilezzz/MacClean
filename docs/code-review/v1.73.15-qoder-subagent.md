**Q1 有没有恒绿断言？** 有，且都被 `r2` 抓到：T12/T16b/T17 只 grep 形状（F13）、

另一条重复：T10 与 T19 用同一个 `frag_fake`，等价——已在 T10 注释里降级为"别过度阻断"的阴性对照。

**Q2 活性探针挡得住"命令根本没执行成功"吗？** 挡得住它声称的那一类（空数组事故、`git grep` 128、

它只证明**命令跑过**，不证明**每条 ERE 能匹配**——模式写错成永不命中就是 rc=1=干净，

**Q3 `scan_text` 这一档有没有洞？** 有：(a) 不接受备案**不会**自我锁死（标题不是一次性字符串，
abs 命中就该改标题），这条站得住；(b) 它继承了"只看第一个片段"的 bug，标题里一个占位串就能给
同一行后面的真 key 开脱（已修，F10）；(c) 以前只有 `run_scan` 接了标题，`--scan-only --staged`
与提交步骤都不过（已补，且 T16b 现在能抓"接错成 VERSION"）。
