## P2 及处置

- **已修（3 条）**：① 扫描器存的根路径改为 `normalizePath` 形态，与盲区清单对得上；② 自检失败输出不再 `print` 整份 `deniedAccessSnapshot()`（未隔离时会把本机真实目录打进日志），改打条数；③ 性能断言不再钉 `totalSize == 8192` 这种随分配器/卷变化的量，改成 `> 0`。
- **转待议（5 条）**：
  1. **探测与列举各 open 一次**：面板根现在是"探针 opendir 一次 + 枚举器再 opendir 一次"，第二次仍无截止。正解是加 `childrenBoundedDetailed(of:)` 一次读取兼作探测与列举，并删掉 `enumerator == nil` 那条兜底分支——那要改 `FileSystem` 的返回契约，跨两张扫描器。
  2. **TTL 短路在面板措辞里被讲成"本轮没能读到"**，最长可谎报 10 分钟（授权其实早已补上）。正解是让 `.unreadable` 带上"上次尝试于 N 分钟前"，banner 相应改措辞；或给面板路径用更短的 TTL。
  3. **扫描器两条早退路径**（安全护栏拒掉的根、`fileExists` 为假的根）仍返回什么都没记的空 summary，界面照样说"没有文件"。默认根一般存在，触发面窄；要修得再引入第三种"未纳入范围"清单。
  4. **`AppLocalizationScanner.directorySize` 仍无截止**：面板列表里每个 `.app`/`.pkg` 算体积走它，卡死只是从根挪到条目。本轮**没有**修它（那是被多个模块共用的递归求和，改语义影响面大），但已把 README 与 `CLEANUP-RULES.md` 的措辞从"面板已纳入"改成明列这条残留。
  5. **`resetWedgedReadsForSelftest()` 清了占位记录却清不回令牌**，等于让"同一个卡死目录一轮只试一次"这条不变量在自检期失效。改名 + 文档写清，或返回被清的 key 集合。

## 附：本轮踩到的两条测试质量教训（已写进 RELEASE-CHECKLIST）

1. **归还并发额度必须"占几条还几条"**，且自检的"额度已恢复"守卫要看**满额**回来，
   不能只看"还剩一分可用"——那一分往往就是它自己要用的。
2. **`A || B` 式的标识符存在性断言是假断言**：它会在实现写错标识符时照样绿（本轮 P0-2 就是这么漏的）。
